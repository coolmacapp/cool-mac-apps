## App directory

A collection organized by each app’s primary category. Each entry includes a concise description, its official website, and a page on Cool Mac Apps for further reading.

### AI

- **Nativ** - Runs open AI models locally on your Mac with a chat interface, live usage analytics, and integrations for coding agents.  
  [Official website](https://blaizzy.github.io/nativ/) · [Read more](https://coolmac.app/apps/nativ)

- **Openbroca** - Uses AI-powered voice dictation to clean up spoken text, insert it at the cursor, and translate speech into multiple languages.  
  [Official website](https://openbroca.com) · [Read more](https://coolmac.app/apps/openbroca)

### Audio & Music

- **Spotifast** - An open-source Spotify player for Mac with Spotify Connect support, customizable themes, and compact Winamp-inspired controls.  
  [Official website](https://spotifast.rocks/) · [Read more](https://coolmac.app/apps/spotifast)

### Calendar & Scheduling

- **Dot** - A menu bar calendar for checking upcoming meetings, receiving alerts, managing Apple Reminders, and creating events without opening a calendar app.  
  [Official website](https://www.trydot.app/) · [Read more](https://coolmac.app/apps/trydot)

### Clipboard

- **Supaste** - A visual Mac clipboard manager with searchable copy history, screenshot text recognition, a notch shelf, and quick-paste shortcuts.  
  [Official website](https://www.supaste.com/) · [Read more](https://coolmac.app/apps/supaste)

### Communication

- **ZapFast** - A lightweight open-source WhatsApp client for macOS designed to work without bundling an embedded web browser engine.  
  [Official website](https://zapfast.rocks/) · [Read more](https://coolmac.app/apps/zapfast)

### Design

- **Compositor** - A layer-based photo editor for macOS designed for image retouching, combining multiple images, and creating visual compositions.  
  [Official website](https://robbietilton.com/compositor) · [Read more](https://coolmac.app/apps/compositor)

- **Refbox** - Keeps visual references such as photos, videos, and 3D models visible while you work in other creative applications on your Mac.  
  [Official website](https://ref.box/) · [Read more](https://coolmac.app/apps/refbox)

### Developer Tools

- **Tray** - Provides a Mac interface for browsing Claude Code projects, sessions, skills, and settings without navigating everything manually.  
  [Official website](https://parcse.com/tray) · [Read more](https://coolmac.app/apps/tray)

- **Wasdy** - A menu bar utility for viewing and managing Claude Code skills and MCP servers from your Mac without switching to another workspace.  
  [Official website](https://wasdy.app/) · [Read more](https://coolmac.app/apps/wasdy)

### File Management

- **DigUp** - Searches local photos, PDFs, recordings, videos, and code using the content inside those files rather than only their filenames.  
  [Official website](https://github.com/ARahim3/DigUp) · [Read more](https://coolmac.app/apps/digup)

- **KarmaDisk** - Visualizes Mac storage, locates duplicate files, and helps clean up space, including lossless compression of supported photos.  
  [Official website](https://www.karmadisk.eu/) · [Read more](https://coolmac.app/apps/karmadisk)

- **Looq** - Extends Finder Quick Look to preview Markdown files, source code, databases, and archives without opening separate applications.  
  [Official website](https://parcse.com/looq) · [Read more](https://coolmac.app/apps/looq)

- **Tilde** - A native alternative to macOS Finder that provides split-view file browsing and customizable ways to arrange and organize files.  
  [Official website](https://tildeformac.com/) · [Read more](https://coolmac.app/apps/tilde)

### Menu Bar

- **Crowny** - Turns the MacBook notch into a control area for coding agents, music playback, clipboard history, timers, and other quick-access tools.  
  [Official website](https://www.crowny.lol/) · [Read more](https://coolmac.app/apps/crowny)

- **Hushtop** - Uses the MacBook notch to surface music, meetings, system controls, and approval prompts from Claude Code and Codex coding agents.  
  [Official website](https://hushtop.app/) · [Read more](https://coolmac.app/apps/hushtop)

- **NotchNook** - Adds a utility panel around the MacBook notch for controlling music, checking calendars, taking notes, setting timers, and holding files.  
  [Official website](https://getnotchnook.com/) · [Read more](https://coolmac.app/apps/notchnook)

### Notes & Knowledge

- **Resurf** - Organizes saved bookmarks, notes, screenshots, and PDFs in a local-first Mac library with full-text search and optional iCloud sync.  
  [Official website](https://resurf.so/) · [Read more](https://coolmac.app/apps/resurf)

- **Spatial.** - A freeform visual canvas for arranging notes, images, videos, and web clips together when organizing ideas or references.  
  [Official website](https://www.get-spatial.com/) · [Read more](https://coolmac.app/apps/getspatial)

### Productivity

- **Cuewake** - Lets you attach context-aware notes, checklists, and reminders to the apps and web pages where you need to see them on your Mac.  
  [Official website](https://cuewake.app/) · [Read more](https://coolmac.app/apps/cuewake)

- **Monocle** - Helps you concentrate on the active Mac window by blurring distracting background windows while keeping your current work visible.  
  [Official website](https://trymonocle.app/) · [Read more](https://coolmac.app/apps/monocle)

- **TapMac** - Uses customizable MacBook tapping gestures to start dictation, edit selected text, and open clipboard history without switching apps.  
  [Official website](https://gettapmac.com/) · [Read more](https://coolmac.app/apps/tapmac)

### Screen Capture

- **Obry** - Keeps screenshots and snippets of text accessible as floating cards on your Mac, with interactions controlled through trackpad gestures.  
  [Official website](https://obry.app/) · [Read more](https://coolmac.app/apps/obry)

- **Recordly** - Creates macOS screen recordings and product demos with automatic zoom effects, smooth cursor animations, and a built-in video editor.  
  [Official website](https://recordly.dev) · [Read more](https://coolmac.app/apps/recordly)

- **Screen Studio** - Records the Mac screen with automated zoom effects and smooth cursor movements, then lets you edit the video in the same app.  
  [Official website](https://screen.studio/) · [Read more](https://coolmac.app/apps/screen-studio)

- **ScreenKite** - Records and edits Mac screen videos with automatic zoom, caption tools, and an editing workflow that supports AI agents.  
  [Official website](https://www.screenkite.com/) · [Read more](https://coolmac.app/apps/screenkite)

- **ShotGlass** - Captures and edits Mac screenshots and videos with automatic zooms, multi-window recording, and 3D MacBook presentation scenes.  
  [Official website](https://shotglass.app/) · [Read more](https://coolmac.app/apps/shotglass)

### Security & Privacy

- **FaceGate** - Protects individual Mac applications using on-device facial recognition, Touch ID, or a password before allowing access.  
  [Official website](https://dweep-desai.github.io/FaceGate-web/) · [Read more](https://coolmac.app/apps/facegate)

- **VPNonly** - Routes selected Mac applications through a WireGuard VPN while leaving other applications on the device's regular connection.  
  [Official website](https://vpnonly.app/) · [Read more](https://coolmac.app/apps/vpnonly)

### System Utilities

- **Alcove** - Adds Dynamic Island-style interactions to the MacBook notch, including live activity updates, notifications, and media playback controls.  
  [Official website](https://tryalcove.com/) · [Read more](https://coolmac.app/apps/alcove)

- **CoolDock** - Adds a customizable secondary Dock to macOS with live widgets, application shortcuts, and quick controls for everyday tasks.  
  [Official website](https://cooldock.app) · [Read more](https://coolmac.app/apps/cooldock)

- **Droppy** - Adds a customizable Dynamic Island-style panel to macOS with a file shelf, clipboard history, live activities, and optional extensions.  
  [Official website](https://getdroppy.app) · [Read more](https://coolmac.app/apps/droppy)

- **DynamicHorizon** - Transforms the MacBook notch into an interactive area for media playback, notifications, timers, and visible system activity.  
  [Official website](https://www.dynamichorizon.app/) · [Read more](https://coolmac.app/apps/dynamichorizon)

- **FaceUnlock** - Enables facial recognition for unlocking a Mac using its webcam, with the existing account password available as a fallback.  
  [Official website](https://macos-faceunlock.zerowarning.in/) · [Read more](https://coolmac.app/apps/faceunlock)

- **Kiiwi** - Simulates mechanical keyboard switches as you type, with selectable recordings and optional mouse click and scrolling sound effects.  
  [Official website](https://kiiwi.app/) · [Read more](https://coolmac.app/apps/kiiwi)

- **Klack** - Plays configurable mechanical keyboard sounds while you type on your Mac, adding simulated typing feedback without physical switches.  
  [Official website](https://tryklack.com) · [Read more](https://coolmac.app/apps/klack)

- **Muro** - Provides live video wallpapers for macOS that can appear on the desktop, lock screen, and screen saver instead of static images.  
  [Official website](https://murowallpaper.com/) · [Read more](https://coolmac.app/apps/muro)

- **Parall** - Launches multiple instances of supported Mac applications with separate Dock icons and distinct profiles where the app allows them.  
  [Official website](https://parall.app/) · [Read more](https://coolmac.app/apps/parall)

- **Perchy** - Turns the MacBook notch into a quick dashboard for cryptocurrency prices, music, calendar events, clipboard history, and files.  
  [Official website](https://getperchy.com/) · [Read more](https://coolmac.app/apps/getperchy)

- **Purge** - An open-source Mac cleanup utility for removing caches, developer-generated files, large files, and leftovers from removed apps.  
  [Official website](https://purgemac.com) · [Read more](https://coolmac.app/apps/purgemac)

- **Shortap** - Lets you trigger supported MacBook actions and Apple Shortcuts by tapping designated areas on either side of the laptop.  
  [Official website](https://shortap.app/) · [Read more](https://coolmac.app/apps/shortap)

- **UTM** - Runs Windows, Linux, macOS, and older operating systems in virtual machines on a Mac, with support for Apple silicon and Intel hardware.  
  [Official website](https://getutm.app/) · [Read more](https://coolmac.app/apps/getutm)

### Video

- **Vidyst** - A video production app for 4K recording, live streaming, and podcasts with simultaneous horizontal and vertical video output.  
  [Official website](https://www.vidyst.com/) · [Read more](https://coolmac.app/apps/vidyst)

### Window Management

- **Betterswitch** - A macOS window switcher that lets you move directly between open windows and organize groups of apps into task-specific workspaces.  
  [Official website](https://www.betterswitch.app/) · [Read more](https://coolmac.app/apps/betterswitch)

### Writing

- **Superwhisper** - An AI dictation app for macOS with offline transcription support, configurable writing modes, and tools for taking meeting notes.  
  [Official website](https://superwhisper.com/) · [Read more](https://coolmac.app/apps/superwhisper)
